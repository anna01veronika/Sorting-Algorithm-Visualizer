# Sorting Algorithm Visualizer

A desktop application built with Java and JavaFX that helps you visualize how different sorting algorithms work in real time.

Instead of running algorithms in fast, hidden loops, this project breaks them down into single steps. This allows the application to draw every comparison, swap, and position change directly onto a JavaFX Canvas at a controlled speed.
Features

    Visualized Algorithms:

        Bubble Sort: Shows step-by-step neighbor comparisons and swaps.

        Insertion Sort: Shows elements shifting to make room for the current key.

        QuickSort: Built with a custom stack (no recursion) to show Lomuto partitioning and pivot placement step by step.

    Real-Time Color Feedback:

        Blue: Normal, unsorted elements.

        Red: Numbers currently being compared or swapped.

        Yellow: The pivot element (QuickSort).

        Green: A smooth sweep animation highlighting the array once it is fully sorted.

    Customizable Array Size: Adjust the number of elements using a slider before starting.
